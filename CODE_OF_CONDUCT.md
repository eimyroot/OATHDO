# Code of Conduct

## Our standard

Collaboration in this repository must remain professional, constructive, and safe.

Contributors, maintainers, reviewers, and users are expected to communicate respectfully, focus criticism on ideas, code, evidence, and outcomes, respect privacy and security boundaries, and avoid harassment, discrimination, threats, intimidation, doxxing, sexualized conduct, or personal attacks.

## Scope

This applies to issues, pull requests, reviews, discussions, and other project-related communication.

## Enforcement

Maintainers may edit or remove content, close or lock conversations, reject contributions, or restrict participation when behavior violates this Code of Conduct. Serious or repeated violations may result in permanent exclusion from project spaces.

## Reporting

Report conduct concerns privately to the repository owner. Do not place sensitive personal information in public issues.

Disagreement is expected. Abuse is not.
